# celebression

JAR успешно собран из исходников для **Minecraft 1.21.4, Fabric Loader 0.16.14+, Fabric API и Java 21**.

Артефакт: `build/libs/celebression-2.0.jar`. Для установки используется именно этот файл, без суффикса `-sources`.

## Что включено

- Все 82 регистрации функциональных модулей базы визуалов.
- Click GUI и необходимые ему UI-библиотеки из Nuclear; реализации его функциональных модулей не импортированы.
- Главное меню и AltManager из последнего `okak.zip`, с брендингом `celebression`.
- Адаптеры GUI к настройкам визуалов, биндам и сохранению конфигурации.
- Восстановленный сериализатор медиаданных.

**Новый HUD ещё не перенесён. Сейчас используется HUD базы визуалов.** Его последний архив и перечень зависимостей сохранены в `provenance/hud-input/`.

## Сборка

Нужны полный JDK 21 и Python 3.12+. В облачной среде установлен Temurin 21.0.13+9 с проверкой опубликованной SHA-256. Повторная установка для Linux x64:

```sh
python3 tools/bootstrap_jdk.py
python3 tools/gradle.py build
```

Запускатель автоматически выбирает установленный Temurin, использует унаследованный прокси и системное хранилище доверенных сертификатов облачной среды. Проверка TLS включена. Другой полный JDK можно указать через `CELEBRESSION_JAVA_HOME`.

На обычной машине с полным JDK 21 доступны `./gradlew build` и `gradlew.bat build`.

Исходники базы остаются в intermediary-именах. Задача `prepareNamedSources` создаёт Yarn-версию в `build/generated/sources/yarn`, а `remapJar` преобразует собранный мод для установки в Minecraft. Старый скрипт, лишь копировавший отсутствующий runtime, не используется.

## Проверка

`build` завершился успешно. Выполнены:

- Компиляция всех исходников базы и интеграции.
- Девять тестов преобразования имён, включая record-компоненты, конфликтующие импорты и сохранение строк reflection.
- JSON round-trip медиаданных и отклонение отсутствующих обязательных полей.
- Проверка структуры 853 Java-файлов, entrypoint и mixin-конфигураций.
- Проверка целостности итогового JAR, наличия entrypoint, 124 mixin-классов, сгенерированного refmap и 11 вложенных библиотек.
- Проверка, что класс меню в итоговом JAR использует production-имена Minecraft.

Игровой запуск, внешний вид и поведение всех функций пока не проверены. Встроенные нативные библиотеки Skija сохранены для Windows/macOS; Linux-версия 0.93.6 в репозитории производителя недоступна и не добавлена.

Лог сборки: `provenance/latest-build.txt`. Никакие конфигурации среды не публиковались.
